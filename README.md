# Victoria Ubani — Portfolio

A responsive, static portfolio for Victoria Ubani, content marketer and copywriter.

## Preview locally

Run any static web server from this folder, for example:

```sh
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Deploy

The site has no build step and can be deployed directly to GitHub Pages, Netlify, Cloudflare Pages, or Vercel.
